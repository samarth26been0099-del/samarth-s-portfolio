# ⚡ Samarth Sahu - Personal Portfolio Website

A sleek, responsive, high-performance personal portfolio website built for **Samarth Sahu**, first-year B.Tech (Electronics & Communication Engineering) student at **JECRC University**, Jaipur.

Designed with modern dark aesthetics, glowing circuit motifs, interactive electronics components, and smooth responsiveness.

---

## 🚀 Tech Stack

- **Frontend Framework:** React 18
- **Bundler & Dev Server:** Vite 6
- **Styling:** Tailwind CSS 3 with custom circuit themes & glowing effects
- **Icons:** Lucide React
- **Celebrations / Interactions:** Canvas-Confetti
- **Deployment Platform:** Optimized for [Vercel](https://vercel.com)

---

## 📌 Website Sections

1. **Home:** Name, "B.Tech Student | AI & Technology Enthusiast", role badges, active status pill, View Projects & Contact buttons, and interactive electronics chassis.
2. **About Me:** Student-friendly engineering introduction, pillars of interest (Hardware & ECE, Software & AI, Innovation Mindset), verified profile dossier.
3. **Education:** B.Tech ECE at JECRC University (Jaipur, India), year, academic coursework, and relevant learning areas (Circuit Theory, Digital Logic, C++, IoT, etc.).
4. **Skills:** Interactive categorized cards for HTML, C++, JavaScript, Python, Artificial Intelligence, Generative AI, Digital Productivity, and IoT & Embedded Systems.
5. **Projects:**
   - *Personal Portfolio Website*
   - *AI Website Project*
   - *Student Productivity Project*
   - Includes interactive details modal, tech stack pills, and GitHub links.
6. **Achievements:** Categorized showcases (Certifications, Hackathons, Courses, Awards, Other Achievements) + interactive guide modal on how to add new milestones.
7. **Contact:** One-click copy email button, LinkedIn, GitHub, Location (Jaipur, India), and functional direct message form.

## 🛠️ Local Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Dev Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```

---

## 🌐 Deploy to Vercel

1. Push this project to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of portfolio website"
   git branch -M main
   git remote add origin https://github.com/samarth26been0099-del/<repo-name>.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com), click **Add New Project**, import your GitHub repository, and click **Deploy**.
3. Vercel will automatically detect Vite and deploy your portfolio live in seconds!
